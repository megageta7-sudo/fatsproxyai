1 Pendahuluan

Kebijakan Privasi ini menjelaskan bagaimana ekstensi browser Flow Mass Downloader ("kami", "ekstensi") mengelola, menggunakan, dan melindungi informasi pengguna saat Anda menggunakan layanan ekstensi ini di browser Google Chrome.

Kami berkomitmen penuh untuk menjaga privasi Anda. Ekstensi ini dirancang dengan prinsip privacy-first di mana semua pemrosesan download dan pemilihan berkas dilakukan secara lokal di perangkat Anda.

2 Data yang Kami Kumpulkan & Cara Penggunaannya

Kami TIDAK PERNAH mengumpulkan, membaca, atau menjual data pribadi Anda (seperti nama asli, alamat email, password, kata kunci pencarian, riwayat penjelajahan umum, atau percakapan).

Data teknis non-pribadi yang diproses oleh ekstensi terbatas pada:

  • Pengaturan Pengguna & Riwayat Download: Nama folder unduhan pilihan Anda dan ID unduhan disimpan secara lokal menggunakan chrome.storage.local hanya untuk memastikan berkas yang sama tidak terunduh dua kali.
  • Status Lisensi & Anonymous Device ID: Ekstensi membuat ID perangkat acak (misal: gabungan nama fauna/flora seperti Tiger-892) untuk memvalidasi periode uji coba (Trial) dan status langganan Lifetime Anda.
  • Validasi Lisensi Webhook: Ekstensi mengirimkan ID anonim tersebut ke server endpoint aman kami (fatsproxyai.vercel.app) hanya untuk memverifikasi apakah akun/perangkat telah teraktivasi status Pro.

Penting: Tidak ada file gambar, prompt kreatif, atau aset yang Anda buat di Google Flow yang dikirim atau diunggah ke server kami. Semua berkas diunduh langsung dari server Google ke folder download lokal komputer Anda.

3 Izin Ekstensi (Chrome Permissions)

Ekstensi ini memerlukan beberapa izin dengan tujuan fungsional spesifik sebagai berikut:

  • downloads: Diperlukan untuk mengotomatiskan penyimpanan berkas gambar yang dipilih ke direktori unduhan komputer Anda secara rapi.
  • storage: Diperlukan untuk menyimpan preferensi folder download, batas unduhan, dan status lisensi di browser Anda.
  • host_permissions (labs.google & subdomain terkait): Diperlukan agar ekstensi dapat membaca tombol aset di halaman Google Flow dan mendownload gambar resolusi penuh.

4 Keamanan Data

Semua komunikasi ke server verifikasi lisensi kami dilakukan melalui protokol terenkripsi HTTPS (SSL/TLS) standar industri. Kami menerapkan langkah-langkah keamanan teknis yang ketat untuk mencegah akses tanpa izin.
